# 微调数据说明

## 数据格式

所有数据为 JSON 数组，每条样本为指令微调三段式：

```json
{
    "system": "作为股票分析师，请基于最新A股数据进行投研风险分析……",
    "user": "请进行基本面风险分析",
    "assistant": "贵州茅台(600519)最新年度财报披露显示……"
}
```

## 目录结构

| 路径 | 大小 | 内容 |
|---|---|---|
| `stock/clean_stock.json` | ~0.6 MB | A股个股投研分析问答（基本面/行业竞争/外部环境风险等） |
| `credit/clean_credit.json` | ~4.6 MB | 信用分析问答（租赁公司、偿债能力、资本充足率等） |
| `economic/clean_economic.json` | ~3.6 MB | 宏观经济分析问答（M2/GDP/CPI/PMI/货币政策等） |
| `industry/clean_industry.json` | ~4.9 MB | 行业金融分析问答（产业链、竞争格局、市场波动等） |

## 完整训练集

上述 4 类数据的合并完整版 `cleaned_train.json`（约 572 MB）因体积原因
不随仓库分发。获取方式：

- 联系仓库维护者获取下载链接；或
- 使用上方 4 个分项文件直接训练（脚本支持任意单个分项）。

## 数据来源与合规

- 数据来源于公开研报、公开新闻与公开财经信息的整理与改写，仅用于学术研究。
- 使用本项目数据训练的模型输出仅供研究参考，**不构成任何投资建议**。
- 如你是相关内容的权利人并认为数据使用不当，请提交 Issue，我们会及时处理。
